# Pitch-Deck Documentation

The project generates short, medium, and long slide decks as PDF and PPTX.
It also builds a descriptive manuscript as PDF and HTML.

| Task | Guide |
| --- | --- |
| Prepare the pinned environment and build both outputs | [Build and verify](build.md) |
| Edit a subject, content length, theme, or citation | [Authoring](authoring.md), [manuscript directory](manuscript/README.md) |
| Locate scripts, token producers, and tests | [Scripts](scripts.md), [source](source.md), [testing](testing.md) |
| Review evidence and publication identity | [Claim ledger](data.md), [standalone guide](standalone.md) |
| Follow maintenance decisions | [Backlog](backlog.md), [commissioning notes](history/ISA.md) |

The repository's tracked `output/` is its archived release snapshot. Use a
disposable checkout for generated verification artifacts.
